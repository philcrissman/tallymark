Count your visitors, not your visitors' secrets.

Tallymark is a tiny, open-source web analytics tool you deploy to your own AWS account in a few minutes. No cookies, no fingerprinting, no consent banner. You get page views, top pages and referrers, and nothing about who your visitors are.

Deploy your own View on GitHub

Features

Everything a personal site needs. Nothing it doesn't.

Tallymark answers three questions — how many people came, what did they read, and where did they come from — and then gets out of the way.

Private by design

No cookies, no local storage, no IDs, no fingerprinting. The tracker sends the path and referrer, and it respects Do Not Track.

A 20-line tracker

A few lines of plain JavaScript using navigator.sendBeacon. No dependencies, no CORS preflight, and nothing that slows your pages down.

Charts you'll actually read

A daily views chart with hover details, quick ranges (today, 7, 30, 90 days, all time), and arrows to step back through history.

Many sites, one deploy

Track as many sites as you like from one deployment. An allowlist makes the endpoint reject page views for sites that aren't yours.

Costs about nothing

Fully serverless: Lambda, API Gateway and on-demand DynamoDB. A typical personal site costs well under a dollar a month.

Your data, your account

Everything runs in your AWS account. There's no third party to trust, and one API call deletes all of a site's data.

Screenshots

A quiet dashboard for a quiet tool.

Built in Elm with elm-charts. Sign in with the API key you chose at deploy time, pick a site, and pick a date range.

How it works

One beacon, one function, one table.

When a page loads, the tracker sends one small POST. A Haskell Lambda function stores it in DynamoDB. The dashboard asks the same function for totals.

Your site ──POST /track──▶ API Gateway ──▶ Lambda (Haskell) ──▶ DynamoDB
                                                  ▲
Dashboard ──GET /stats, /sites (Bearer key)───────┘
(Elm, on S3)
  • BackendHaskell on AWS Lambda, using hal and amazonka
  • DashboardElm with elm-charts
  • StorageDynamoDB, single table, pay per request
  • InfraOne AWS SAM template, deployed with one script

Get started

Up and running in about ten minutes.

You need an AWS account, the AWS CLI and the AWS SAM CLI. Download a release so you don't have to build anything, then:

# 1. Download and unpack the latest release
curl -LO https://github.com/philcrissman/tallymark/releases/latest/download/tallymark.tar.gz
tar xzf tallymark.tar.gz && cd tallymark-*

# 2. Configure: pick an API key and list your sites
cp tallymark.env.example tallymark.env
$EDITOR tallymark.env

# 3. Deploy
./scripts/deploy.sh

The script prints your dashboard URL. Sign in with your key, click Get Tracker Code, and paste the snippet into your site.
